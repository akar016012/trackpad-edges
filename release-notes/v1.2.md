Trackpad Edges now runs on more versions of macOS.

- The app supports macOS 13 Ventura or later, instead of only the newest version of macOS.
- On systems before macOS 26, the glass styles for the seek preview look frosted.

All testing so far has used macOS 27.2, so please report any problem that you see on an earlier version.

If you use version 1.1, this update can install itself.

The app needs a Mac with Apple silicon and a Force Touch trackpad, running macOS 13 or later.
