# Settings

Status: planned. The settings window has not been built yet.

The settings window is built with AppKit and opens from the menu bar item. No website documents a similar app's real settings layout, so the layout and ranges here are this project's own design.

## General

| Setting                  | Planned behavior                                                 |
| ------------------------ | ---------------------------------------------------------------- |
| Swap sides               | This option swaps the volume and brightness edges.               |
| Bottom quarter only      | This option limits slides to the bottom quarter of each edge.    |
| Require a physical click | This option makes slides start on a click rather than on touch.  |
| Require a modifier key   | This option makes slides start only while a chosen key is held.  |
| Edge width               | This slider sets the width of the strips, with a default of 10%. |
| Sensitivity              | This slider sets how far a finger travels for each step.         |
| Launch at login          | This option starts the app when you log in.                      |
